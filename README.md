# Secure Grant Database

University Research Grant Management System, built for the Database Security
course (5th year Engineering in Cybersecurity).

Stack: Windows 11 (VMware), XAMPP, MariaDB 10.4, PHP 8.2.

## Structure
- sql/   : database scripts
- docs/  : analysis, notes and evidence
- app/   : PHP application (coming soon)

Status: Phase 1 complete.
